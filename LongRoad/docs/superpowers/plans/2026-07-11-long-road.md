# The Long Road Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build The Long Road — a journey-survival Roblox game where players trek a huge 4-zone map to an Extraction Point while managing hunger/warmth, fires, monsters, hazards, and PvP.

**Architecture:** Rojo project (same workflow as Dress to Survive) with a single `Main.server.lua` bootstrap requiring service ModuleScripts in dependency order. The map is baked once in Studio via a `MapBuilder` module (terrain sculpt → marker parts → `ModelPlacer` swaps markers for Harvey's realistic models or placeholders). All gameplay state lives in player/character Attributes so client HUD reads it without extra remotes.

**Tech Stack:** Luau, Rojo 7, Roblox smooth Terrain, ProximityPrompts, DataStoreService.

**Testing reality:** There is no automated test runner for this project. Each task's verify steps are: (1) `rojo build` must succeed (syntax gate), (2) a specific Studio play-test checklist using `DebugService` chat commands. Do not skip the Studio checklist items — they are the tests.

Each service ModuleScript returns a table with an `Init(deps)` function. `Main.server.lua` requires them all, calls `Init` in dependency order, and passes a shared `deps` table so services can call each other (e.g. `deps.Inventory:GiveItem(...)`). No `_G`, no WaitForChild-API-object pattern.

**Attribute contract (used everywhere):**
- Player attributes: `Hunger`, `Warmth`, `Currency`, `CheckpointIndex` (0 = start), `SquadId` (0 = none), `HostileUntil` (unix time), `Wet` (bool), `Sick` (bool), `BestTime`, `Completions`, `RunStartTime`
- Character attributes: none needed; humanoid state is authoritative.
- Item instances (Tools) carry `ItemId` attribute matching `ItemDefs`.

```lua
-- RemoteSetup: creates (server) or fetches (client) all RemoteEvents
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local RunService = game:GetService("RunService")

local REMOTE_NAMES = {
	-- client -> server
	"EatItem", "UseItem", "EquipSlot", "DropItem", "PlaceFire", "AddFuel",
	"CookMeat", "SwingWeapon", "FireProjectile", "SquadInvite", "SquadResponse",
	"SquadLeave", "BuyKit", "SetSprinting",
	-- server -> client
	"InventoryUpdate", "Notify", "TimeUpdate", "SquadUpdate", "RunFinished",
}

local RemoteSetup = {}
function RemoteSetup.Get()
	local folder
	if RunService:IsServer() then
		folder = ReplicatedStorage:FindFirstChild("Remotes") or Instance.new("Folder")
		folder.Name = "Remotes"
		folder.Parent = ReplicatedStorage
		for _, name in ipairs(REMOTE_NAMES) do
			if not folder:FindFirstChild(name) then
				local r = Instance.new("RemoteEvent")
				r.Name = name
				r.Parent = folder
			end
		end
	else
		folder = ReplicatedStorage:WaitForChild("Remotes")
	end
	local remotes = {}
	for _, name in ipairs(REMOTE_NAMES) do
		remotes[name] = folder:WaitForChild(name)
	end
	return remotes
end
return RemoteSetup
```

- [ ] **Step 1: Write `TerrainGen.lua`.** Core approach: iterate the map in 40-stud cells; compute height from layered `math.noise` with zone-specific amplitude/material; fill terrain columns with `Terrain:FillBlock`. Carve the river band as Water; raise the mountain band; flatten a 30-stud road strip along X=0 through Suburbs and City. Key code:

```lua
local TerrainGen = {}
local Config = require(game:GetService("ReplicatedStorage").GameConfig)

local CELL = 40
local SEED = 1337

local function zoneAt(z)
	for i, zone in ipairs(Config.ZONES) do
		if z >= zone.zStart and z < zone.zEnd then return i, zone end
	end
	return #Config.ZONES, Config.ZONES[#Config.ZONES]
end

-- Height profile per zone index: {baseHeight, amplitude, material}
local PROFILE = {
	[1] = { base = 20, amp = 12, material = Enum.Material.Grass },      -- Forest: rolling
	[2] = { base = 16, amp = 5,  material = Enum.Material.Grass },      -- Suburbs: gentle
	[3] = { base = 24, amp = 30, material = Enum.Material.Rock },       -- Highlands: rugged
	[4] = { base = 14, amp = 4,  material = Enum.Material.Concrete },   -- City: flat rubble
}

function TerrainGen.HeightAt(x, z)
	local zi = zoneAt(z)
	local p = PROFILE[zi]
	local n = math.noise(x / 400 + SEED, z / 400 + SEED)      -- broad hills
	local n2 = math.noise(x / 90, z / 90) * 0.3               -- detail
	local h = p.base + (n + n2) * p.amp
	-- Mountain pass: raise dramatically, leaving a walkable saddle near X=-400
	if z >= Config.MOUNTAIN_Z[1] and z <= Config.MOUNTAIN_Z[2] then
		local ridge = 60 * math.sin(math.pi * (z - Config.MOUNTAIN_Z[1]) / (Config.MOUNTAIN_Z[2] - Config.MOUNTAIN_Z[1]))
		local saddle = math.clamp(math.abs(x + 400) / 300, 0, 1) -- 0 at pass, 1 away
		h += ridge * saddle
	end
	-- River: carve below water level
	if z >= Config.RIVER_Z[1] and z <= Config.RIVER_Z[2] then
		h = 2
	end
	-- Road strip along X=0 through Suburbs and City: flatten to zone base
	if math.abs(x) < 15 and ((z >= 3000 and z < 6000) or z >= 9000) then
		h = p.base
	end
	return h, p.material
end

function TerrainGen.Build()
	local terrain = workspace.Terrain
	terrain:Clear()
	local halfW = Config.MAP_WIDTH / 2
	for x = -halfW, halfW - CELL, CELL do
		for z = 0, Config.MAP_LENGTH - CELL, CELL do
			local h, mat = TerrainGen.HeightAt(x + CELL / 2, z + CELL / 2)
			local cf = CFrame.new(x + CELL / 2, h / 2, z + CELL / 2)
			terrain:FillBlock(cf, Vector3.new(CELL, h, CELL), mat)
		end
		if x % 400 == 0 then task.wait() end -- yield so Studio stays responsive
	end
	-- River water
	local rz1, rz2 = Config.RIVER_Z[1], Config.RIVER_Z[2]
	terrain:FillBlock(
		CFrame.new(0, 8, (rz1 + rz2) / 2),
		Vector3.new(Config.MAP_WIDTH, 12, rz2 - rz1),
		Enum.Material.Water
	)
	print("[TerrainGen] done")
end

return TerrainGen
```

Core scatter helper (use for all random placement):

```lua
local rng = Random.new(1337)
local function scatter(count, zStart, zEnd, minGap, makeName)
	local placed = {}
	local tries = 0
	while #placed < count and tries < count * 20 do
		tries += 1
		local x = rng:NextNumber(-Config.MAP_WIDTH/2 + 50, Config.MAP_WIDTH/2 - 50)
		local z = rng:NextNumber(zStart + 20, zEnd - 20)
		if math.abs(x) < 25 then continue end -- keep road clear
		local ok = true
		for _, p in ipairs(placed) do
			if (Vector2.new(x, z) - p).Magnitude < minGap then ok = false break end
		end
		if ok then
			table.insert(placed, Vector2.new(x, z))
			local h = TerrainGen.HeightAt(x, z)
			makeMarker(makeName(), Vector3.new(x, h, z))
		end
	end
end
```

### Task 5: DayNightService + Effects client

**Files:**

- [ ] **Step 1: Write `DayNightService.lua`.** API: `Init(deps)`, `IsNight(): bool`, `IsRaining(): bool`, `ForceState(isNight)`, `ForceRain(on)` (the Force* functions skip the clock to the requested state — used by DebugService). Loop: `task.spawn` cycle — day (`ClockTime` tweened 6→18 over `DAY_LENGTH`), night (18→6 over `NIGHT_LENGTH`). At each day start, roll `RAIN_CHANCE`; if raining, spawn rain window of `RAIN_DURATION` at a random offset within the day. Set `Lighting.ClockTime` each second (no per-frame updates needed); fire `Remotes.TimeUpdate:FireAllClients(isNight, isRaining)` on state changes. Night also sets `Lighting.Ambient = Color3.fromRGB(10,10,20)`; day restores `Color3.fromRGB(70,70,70)`.

- [ ] **Step 2: Write `Effects.client.lua`.** Listens to `TimeUpdate` and player attribute changes:

### Task 7: SurvivalService — hunger, warmth, sickness, sprint

**Files:**
- Create: `src/ServerScriptService/Services/SurvivalService.lua`

- [ ] **Step 1: Write `SurvivalService.lua`.** On `PlayerAdded`/spawn: set attributes `Hunger=100, Warmth=100, Wet=false, Sick=false`; WalkSpeed = `WALK_SPEED`. Main loop — one `task.spawn` per server ticking every `SURVIVAL_TICK` second over all players:

```lua
local function tickPlayer(player)
	local char = player.Character
	local hum = char and char:FindFirstChildOfClass("Humanoid")
	if not hum or hum.Health <= 0 then return end
	local root = char:FindFirstChild("HumanoidRootPart")
	if not root then return end

	-- Hunger
	local hungerDrain = Config.HUNGER_DRAIN
	if player:GetAttribute("Sprinting") then hungerDrain *= Config.HUNGER_SPRINT_MULT end
	if player:GetAttribute("Sick") then hungerDrain *= Config.SICK_HUNGER_MULT end
	local hunger = math.max(0, player:GetAttribute("Hunger") - hungerDrain * Config.SURVIVAL_TICK)
	player:SetAttribute("Hunger", hunger)

	-- Warmth drain
	local drain = deps.DayNight.IsNight() and Config.WARMTH_DRAIN_NIGHT or Config.WARMTH_DRAIN_DAY
	if deps.DayNight.IsRaining() then drain *= Config.WARMTH_RAIN_MULT end
	local z = root.Position.Z
	if z >= Config.MOUNTAIN_Z[1] and z <= Config.MOUNTAIN_Z[2] then drain += Config.WARMTH_MOUNTAIN_EXTRA end
	if player:GetAttribute("Wet") then drain *= 2 end

	-- Warmth regen sources override drain
	local warmth = player:GetAttribute("Warmth")
	if deps.Fire.IsNearFire(root.Position) then
		warmth = math.min(Config.STAT_MAX, warmth + Config.FIRE_WARMTH_REGEN * Config.SURVIVAL_TICK)
	elseif isNearCheckpoint(root.Position) then
		warmth = math.min(Config.STAT_MAX, warmth + Config.SHELTER_WARMTH_REGEN * Config.SURVIVAL_TICK)
	else
		warmth = math.max(0, warmth - drain * Config.SURVIVAL_TICK)
	end
	player:SetAttribute("Warmth", warmth)

	-- Penalties
	if hunger <= 0 then hum:TakeDamage(Config.STARVE_DPS * Config.SURVIVAL_TICK) end
	if warmth <= 0 then hum:TakeDamage(Config.FREEZE_DPS * Config.SURVIVAL_TICK) end
	local canSprint = hunger > Config.LOW_STAT
	local cold = warmth < Config.LOW_STAT
	hum.WalkSpeed = cold and Config.COLD_WALK_SPEED
		or (player:GetAttribute("Sprinting") and canSprint and Config.SPRINT_SPEED)
		or Config.WALK_SPEED
end
```

  Also: `SetSprinting` remote sets the `Sprinting` attribute (server checks hunger before honoring). Swimming detection: `Humanoid.StateChanged` → on `Swimming` state entered, if not already Wet: `Warmth -= SWIM_WARMTH_HIT`, `Wet=true`, schedule `Wet=false` after `WET_DURATION` (reset timer if re-entered). Toxic zones: each tick, if within 30 studs of a `Marker_ToxicZone`, take 4 damage/s and show Notify "Toxic air!" once per entry. API: `Eat(player, slot)` — validates via Inventory (`HasItem`), applies `hunger += def.hunger`, rolls `sickChance` → sets `Sick=true` for `SICK_DURATION`; Medkit heals `def.heal`; called from `EatItem`/`UseItem` remotes.

No — attributes only; instead just wait ~1 min and watch the bar move a few points). Sprint with Shift raises speed; hold sprint and confirm hunger drains faster.
